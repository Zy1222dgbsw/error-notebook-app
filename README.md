# 📓 智能错题本 — Smart Error Notebook

> 拍照识别错题 + AI 智能解答 + 学科分类管理  
> 一门编程课的课程项目，用技术解决真实学习痛点

## 🎯 项目背景

学生在日常学习中积累大量错题，手动抄录费时费力，而且缺乏系统的整理和复习工具。本项目利用 Web 技术，实现"拍照 → OCR 识别 → AI 解答 → 学科分类存储"的完整工作流，让错题管理变得简单高效。

## ✨ 功能特性

- 📸 **拍照 / 上传录入** — 调用手机摄像头拍照或从相册选择图片
- 🔍 **OCR 文字识别** — 基于 Tesseract.js，浏览器端离线识别中英文文字
- 🤖 **AI 智能解答** — 支持 Pollinations AI（免费）、DeepSeek、自定义 API，自动给出解题思路和知识点总结
- 📚 **学科分类管理** — 自定义学科（数学、英语、物理……），按学科整理错题
- 🔎 **搜索与筛选** — 按学科筛选、关键词搜索错题
- 💾 **本地持久化** — 使用 localStorage 存储，无需后端服务器
- 📱 **响应式设计** — 手机端和桌面端均可流畅使用
- ⚙️ **多 AI 提供商** — 灵活切换 AI 服务，支持自定义接口

## 🚀 使用方法

### 快速开始

1. 下载项目或克隆仓库：
   ```bash
   git clone https://github.com/Zy1222dgbsw/error-notebook-app.git
   ```

2. 直接在浏览器中打开 `index.html`

3. 开始使用：
   - 点击「拍照」或「选择图片」上传错题照片
   - 点击「开始识别」提取文字
   - 选择学科分类，保存错题
   - 在「错题本」中查看、搜索、管理
   - 点击「AI 解答」获取智能分析

### AI 配置（可选）

默认使用免费的 Pollinations AI，无需配置。如需更好的中文效果：

1. 点击右上角 ⚙️ 设置
2. 选择「DeepSeek」并填入 API Key
3. 或选择「自定义接口」接入其他 AI

## 📖 开发故事

### 版本演进

- **v0.1** — 项目启动，搭建 HTML/CSS 基础框架
- **v0.2** — 实现拍照上传与 Tesseract.js OCR 识别
- **v0.3** — 集成 AI 解答功能，支持多提供商
- **v0.4** — 添加学科管理和 localStorage 持久化
- **v0.5** — UI 优化、响应式适配、bug 修复

### 遇到的问题与解决

| 问题 | 解决方案 |
|------|----------|
| Tesseract.js 首次加载慢 | 使用 CDN 加载 + 显示加载进度 |
| AI API 可能不可用 | 实现备用答案机制，提供设置入口 |
| 手机拍照图片过大 | 压缩为 JPEG 格式，减小存储压力 |
| 中文 OCR 准确率 | 配置 chi_sim+eng 双语识别 |
